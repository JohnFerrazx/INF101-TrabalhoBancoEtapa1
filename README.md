Este projeto foi desenvolvido como parte da Etapa 1 do trabalho da disciplina INF01, com o objetivo de aplicar os fundamentos da linguagem C++ na criação de um sistema de registro e gestão de contas bancárias. Nesta etapa, foi implementado o cadastro e gerenciamento de uma conta bancária utilizando variáveis individuais. O sistema possui um menu interativo que permite cadastrar e consultar a conta, verificar o saldo, alterar o tipo da conta e ativar ou desativar a conta, permanecendo em execução até que o usuário escolha a opção de saída. Também foram implementadas validações para garantir que o número da conta seja positivo, o saldo inicial não seja negativo e o tipo de conta seja válido. Durante o desenvolvimento, foram utilizados conceitos básicos de C++, como variáveis dos tipos int, string, double e bool, estruturas condicionais if/else, estrutura de repetição do while, estrutura switch e comandos de entrada e saída cin e cout. Esta primeira etapa serve como base para a evolução do sistema nas próximas etapas, que utilizarão arrays, funções e persistência de dados em arquivos.
